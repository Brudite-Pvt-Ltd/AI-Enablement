# Python PEP 8 Conventions

## Purpose

The `pep8-conventions` folder is created to help students and beginners understand:

- What bad Python code looks like
- How to write clean, readable, and professional Python code
- Why PEP 8 coding standards are important in real-world and industry projects

Python allows multiple ways to write code, but not all ways are considered good or professional.

---

## Folder Structure

pep8-conventions/
│── README.md
│── bad_code.py # Examples of poor coding practices
│── good_code.py # PEP 8 compliant and industry-style code

---

## How to Use This Folder

1. Open `bad_code.py`
2. Observe the coding issues and poor practices
3. Open `good_code.py`
4. Compare both files line by line
5. Read the comments to understand why the good version is preferred

---

## Topics Covered

- Variable naming conventions
- Indentation and spacing
- Line length and readability
- Function naming and design
- Use of constants instead of magic numbers
- Proper use of comments
- Import statements
- Code readability and maintainability

---

## Final Note 

Good code is not about writing more code.  
It is about writing code that others can read, understand, maintain, and scale.

Learning and following PEP 8 conventions early helps you:

- Write professional-quality code
- Perform better in interviews
- Reduce bugs and errors
- Collaborate effectively in teams
- Develop strong coding habits for your career
